# Managing `AGENTS.md`

The non-negotiable workflow is:

1. Update Memoryledger records.
2. Review and accept the records with reasons.
3. Render/build derived files.
4. Export them to their configured destinations.
5. Never directly patch generated targets.

Ownership is detected from configuration and the generated marker
`<!-- Generated by memoryledger. Do not edit directly. -->`. A manual file is
protected even if `--backup` is supplied. Move manual material through the
adoption workflow instead.
